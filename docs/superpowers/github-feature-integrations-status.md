- 游客和免费用户的普通检查不占用真实模型，返回规则兜底与 `premium_required`；显式高级请求才运行模型。

### 决策

此前“模型尚未安装”的说法不准确。模型和依赖此前已经安装；V108 已完成启用、真实推理和本地质量验收。

### 2026-07-12 V108 验收结论

- RTX 5090、Torch `2.11.0+cu128`、CUDA `12.8` 和离线 Hugging Face 缓存均可用。
- `600519.SH`、`AAPL`、`0700.HK` 均完成 64 根历史 K 线输入与 5 根模型输出，三个市场都只在真实成功后标记 `kronos_model_used=true`。
- 首次服务实测模型加载约 `2.15s`，推理约 `287.6ms`；模型复用后 AAPL/港股推理约 `29.3ms`/`31.1ms`。
- 浏览器复验命中模型缓存，推理约 `35.2ms`，峰值显存约 `42.9MB`；V108 独立探针峰值约 `41.5MB`。
- A 股和港股端到端请求仍可能被网络行情源拖到约 8 秒；页面会把行情超时与模型推理分开展示，不伪装成模型失败。
- 进程内模型按模型、tokenizer、设备、上下文和离线策略缓存；默认并发上限为 1，优先本地缓存，不自动联网下载模型。
- 中文/英文、桌面 1280、移动 390、游客规则兜底、高级用户真实模型和信息分析边界均已浏览器验收。
- V108 门禁通过：`DSA_PLATFORM_KRONOS_RTX5090_V108_OK`；V58 兼容门禁和发布包覆盖继续通过。

后续只做回归、性能监测、数据质量改进和历史误差评估。Kronos 输出继续明确标为实验性资讯和数据，不提供买卖指令、仓位、目标价或收益承诺。
