# DSA V117 六项功能体验与 Ollama 本地验收收口

日期：2026-07-13
范围：`E:\DSA项目` 本地开发与验收，不代表生产上线或数据商业授权。

## 目标

把近期 GitHub 项目接入形成的六项 DSA 产品能力放在同一条真实用户链路中验收，并修复影响免费用户体验的运行时和界面问题：

1. Kronos K 线实验性模型。
2. a-stock-data A 股专项数据增强。
3. AlphaSift 可解释市场筛选。
4. Anthropic Financial Services 研究工作流。
5. DSA 原生市场工作台。
6. DSA 原生市场脉搏、公开首页与私人自选简报。

其中第 5、6 项为参考 OpenStock 与 ai-market-pulse 产品思路后在 DSA 内原生实现的能力，不宣称安装了完整上游运行时，也不把上游代码许可解释为数据商业授权。

## 本阶段改进

- 港股、美股详情优先使用公开 Yahoo 图表行情与历史数据兜底，保留来源、新鲜度和降级提示。
- 市场工作台总览使用轻量快照，详情页再加载完整历史和资料，避免重复慢查询。
- 直达股票链接按最后一次请求更新总览，防止旧的 A 股请求覆盖港股或美股页面。
- 市场来源、时间、数值和降级代码均按中英文界面格式化，不直接暴露内部状态代码。
- AlphaSift 允许显式配置使用过期筛选快照快速降级，并明确标记 `snapshot_cache_stale`。
- 游客首页不建立需要登录的任务事件流，减少无意义 401/重连噪声。
- 筛选结果在当前浏览器会话内短期保留，刷新后仍可继续比较。

## 真实验收范围

- Ollama：确认本地服务可达，使用本地模型分别完成 AAPL 与 `600519.SH` 信息分析；输出不得包含买卖动作，且必须保留“仅供信息分析”边界。
- Kronos：RTX 5090 真实模型探针，记录模型加载、推理耗时、显存、输入与输出 K 线数量。
- A 股增强：公告、资金流、板块、研报和龙虎榜通道逐项报告可用或降级，不伪造缺失数据。
- AlphaSift：筛选任务完成、候选结果可见、缓存状态可解释。
- Financial Services：公司、经营、行业和公开事件四类工作流可匿名查看。
- 市场工作台/市场脉搏：A 股、港股、美股总览与股票详情一致，桌面和移动端无横向页面溢出。

## 安全与产品边界

- 只提供资讯、客观数据、用户自定义条件提醒和实验性模型结果。
- 不提供投资建议、交易指令、目标价、仓位建议或收益承诺。
- 不提交 API Key、Token、密码、生产密钥或真实支付配置。
- 不删除历史报告、数据库、用户数据或已有本地验收证据。
- 真实支付、生产部署、域名、HTTPS/WAF、法律文案和数据授权继续暂停。
