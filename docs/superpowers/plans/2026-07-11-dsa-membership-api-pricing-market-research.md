# DSA 会员 API 额度、成本与香港市场定价调查

状态：2026-07-12 已更新产品额度、月/季/年价格和到期失效规则；真实 Token 与使用率仍需继续验证。

## 1. 产品定位与边界

DSA 只提供市场资讯、公开数据整理、指标计算和信息分析，不提供个性化投资建议、买卖指令、目标价、仓位建议或收益承诺。

会员费与港股实时行情授权费分开计算。基础会员默认使用依法可用的网络数据、延迟数据或已获授权的数据源；没有取得市场数据分发授权前，不把港股实时串流行情作为付费权益销售。

## 3. 单次查询成本假设

计算采用保守条件：输入全部按缓存未命中计费，人民币兑港币暂按 `1 CNY = 1.08 HKD` 估算。

| 查询类型 | 输入 / 输出假设 | 模型 | 单次人民币 | 单次港币约值 |
| --- | ---: | --- | ---: | ---: |
| 普通 API 查询 | 8K / 2K | V4 Flash | ¥0.012 | HK$0.013 |
| 较详细普通分析 | 20K / 5K | V4 Flash | ¥0.030 | HK$0.032 |
| Pro 深度分析 | 20K / 5K | V4 Pro | ¥0.090 | HK$0.097 |
| 重型 Pro 报告 | 50K / 10K | V4 Pro | ¥0.210 | HK$0.227 |

实际运营预算按理论 API 成本的 **3 倍**预留，用于覆盖更长输出、重试、偶发失败、缓存未命中和模型价格变化。

公式：

```text
Flash 成本 = 输入 Token / 1,000,000 * ¥1
           + 输出 Token / 1,000,000 * ¥2

Pro 成本 = 输入 Token / 1,000,000 * ¥3
         + 输出 Token / 1,000,000 * ¥6
```

## 4. 五级会员结构

### 4.1 未注册游客

- 网络查询：开放，受单 IP、单设备和全站速率限制。
- 平台普通 API：每个有效网络身份赠送 5 次 V4 Flash 查询。
- 不开放 V4 Pro、BYOK、长期历史和高级提醒。
- 5 次用完后仍可继续使用不消耗 AI 的网络查询，并引导注册。

成本：

```text
5 * HK$0.013 = HK$0.065 理论 API 成本
按 3 倍预算预留 = 约 HK$0.20 / 游客身份
```

防滥用要求：

- 不长期保存原始 IP；使用带盐哈希标识和第一方设备 Cookie。
- 共享网络用户可通过邮箱注册获得独立额度。
- 代理池、批量账号、异常并发和自动化请求触发验证码、冷却或拒绝。
- 必须在隐私政策中说明 IP/设备标识的用途、保存期限和删除规则。

### 4.2 普通客户（当前确认基准）

- 网络查询：开放，合理限速。
- 普通 API：每周 5 次 V4 Flash，约每月 20 次。
- Pro 体验：邮箱验证后每周 1 次；注册首月可额外赠送 1 次。
- 保存有限历史、自选股和条件提醒。
- 不支持用户自己的 API。

Flash 和 Pro 都按周发放，目的是形成每周回访习惯。页面可按 4 周展示约 20 次 Flash + 4 次 Pro；年度成本预算使用 `52 周 / 12 月` 的月均值，避免低估。

按全年月均口径，正常月份理论成本：

```text
约 21.67 次 Flash + 4.33 次 Pro
= 21.67 * HK$0.013 + 4.33 * HK$0.097
= 约 HK$0.70

按 3 倍预算预留 = 约 HK$2.11 / 活跃免费用户 / 月
```

首月增加 1 次 Pro 后，3 倍预算约 HK$2.40 / 人。

该额度已经作为当前产品基准，不再与旧的低频 Pro 体验方案并列。仍需通过账号、IP、设备、并发、验证码和自动化行为识别控制批量滥用。

### 4.3 PLUS

建议价格：**HK$58/月，HK$158/季，HK$568/年**。

- 保留与普通客户相同的免费赠送额度：每周 5 次 Flash + 每周 1 次 Pro；PLUS 付费不额外增加平台模型额度。
- 注册首月额外 1 次 Pro 仍按普通客户规则执行；升级 PLUS 不会重置注册首月或重复发放奖励。
- AI 分析只使用用户自己的官方 API Key（BYOK），或在安全连接能力完成后使用用户自有本地模型。
- 用户自有本地模型运行在用户自己的设备或环境中，不是 DSA 服务器 Ollama。
- PLUS 会员费覆盖 DSA 数据整理、报告流程、服务器、历史、自选、提醒、筛选、比较和保存等会员服务，不包含模型 Token 成本。
- BYOK 和用户自有本地模型仍受 DSA 服务器、数据源、并发和防滥用公平使用上限约束。
- 当前纯 Web 产品尚未关闭用户自有本地模型安全连接链；正式完成前，PLUS 先开放 BYOK，不宣传本地模型已经可用。

PLUS 的成本包含普通客户免费赠送额度的月均三倍 AI 安全预算 HK$2.11，以及每月 HK$5 服务器/任务队列/基础客服预留：

### 4.6 API 加油包（初版建议，待最终确认）

建议先只提供一个容易理解的混合加油包：**HK$28/包，增加 168 Flash + 28 Pro**。价格和两类次数都以“8”结尾，经营目标为单包贡献利润率约 30%。

适用规则：

1. 仅限有效 PRO/MAX 会员购买；普通客户需要升级会员，PLUS 继续使用 BYOK 或用户自有本地模型。
2. 加油包只增加次数，不改变会员等级、可选模型目录、并发优先级或其他会员权益；高成本模型仍按权重扣减 Pro 次数。
3. Flash 或 Pro 任一余额不足时均可购买；两类次数分别入账、分别扣减，不能相互兑换。
4. 支付成功后立即入账并生成独立额度流水；先扣会员基础额度，再扣加油包额度。
5. 加油包额度在当前会员月结束或会员 `expires_at` 到达时失效，以较早者为准；未使用部分不退款、不折现、不转让、不结转。
6. 购买页必须在付款前显示准确失效时间、剩余可用时长和“不结转”提示；临近到期仍允许购买，但必须二次确认。
7. 单用户每会员月可购买数量和全站销售数量由后台预算风控配置，不宣传无限购买。

### 4.7 会员期限、额度发放与到期规则

1. 月包有效 1 个会员月，季包有效 3 个会员月，年包有效 12 个会员月；会员月从实际生效时间开始计算，不强制按自然月对齐。
2. 季包和年包按会员月逐月发放额度，不在付款当天一次性发放全部季度或年度 API 次数。
3. 每个会员月未使用的 Flash、Pro 和其他会员 API 额度在该会员月结束时自动失效，不累计、不结转。
4. 会员到期时间以服务端 `expires_at` 为准。到期后立即停止平台会员 API 和 BYOK 分析权限，所有剩余额度同时失效。
5. 未使用额度不退款、不折现、不转让、不兑换现金，也不因提前续费或自动续费而结转；法定退款、平台重大故障补偿或人工运营补偿另按单独政策处理。
6. 续费成功后按新会员周期发放新额度；已经失效的旧周期额度不会恢复。
7. 会员到期后仍允许用户进入账号页管理、禁用、更新或删除自己保存的 API Key，但不能通过 DSA 发起 BYOK 请求。
8. 请求接收和实际模型调用前都必须检查有效期。到期前已排队但尚未调用模型的任务，在到期后不得继续消耗会员 API；已经发往供应商的单次调用可以完成，但不得重试或发起后续模型调用。
9. 购买页、结算页和会员权益页必须在付款前明确展示“不退款、不折现、不结转、到期失效”和额度按会员月发放的规则。

## 6. 港股实时数据不能混入基础会员成本

- Level 1：HK$120 / 用户 / 月。
- Level 2：HK$200 / 用户 / 月。
- 更完整深度数据费用更高。

官方来源：

- https://www.hkex.com.hk/Services/Rules-and-Forms-and-Fees/Fees/Securities-%28Hong-Kong%29/Market-Data/End_users?sc_lang=zh-HK

## 7. 贡献利润与 Token 成本保护规则

当前经营口径调整为：PLUS 保留普通客户免费赠送额度，但月费不购买额外平台模型额度，主要覆盖 BYOK/用户自有本地模型接入和 DSA 会员服务；PRO 和 MAX 都不以 Token 差价盈利，而是在扣除 AI 三倍安全预算、支付费用和服务器/客服预留后保持接近 HK$50 的月均贡献利润。这些数字都不等于公司最终净利润。

必须实现以下运营控制：

1. 每次模型调用记录模型、输入/输出 Token、缓存命中、重试和实际成本，不记录 API Key。
2. Flash 和 Pro 分开计数，禁止把深度分析伪装成普通查询。
3. 设置用户日限额、月限额、并发限额和全站预算熔断。
4. 达到单用户 AI 安全预算的 80% 时提醒，100% 时停止平台 API、等待下周期、购买 API 加油包或切换 BYOK。
5. 每月按 P50/P95 Token 用量重算贡献利润；PRO 或 MAX 的预测月均贡献利润明显低于 HK$45 时，提前复核价格、额度、输出长度和重试策略。
6. 模型涨价超过 10%、异常重试率超过 5%或支付成本变化时自动触发人工复核。
7. PRO 或 MAX 的实际月度贡献利润高于目标且不是风险缓冲所需时，优先增加 API 查询额度或提升用户可用性，而不是把 Token 差额作为额外利润。
8. 额度账本必须记录 `entitlement_start`、`entitlement_end`、会员月序号和失效状态；查询时同时验证会员有效期与当前会员月额度，不能只检查剩余次数。
9. 新会员月开始前先关闭上一周期额度，再发放新额度；续费不能把旧周期余额带入新周期。
