# DSA 与香港财经产品简单对比及优劣势报告

- 日期：2026-07-12
- 用途：用简单方式说明各产品卖点、优缺点及 DSA 的市场位置
- 价格口径：公开官网价格；TradingView 按年付月均价并以 `US$1 ≈ HK$7.8` 粗略换算

## 一句话结论

这些产品不是完全相同的竞争者：

- **HKET、经济一周**主要卖财经新闻、专家内容和会员社群。
- **AASTOCKS**主要卖港股监察和本地市场数据工具。
- **TradingView**主要卖专业图表、技术指标和交易工具。
- **ET Net IQ**主要卖港股 Level 2 实时串流行情。
- **DSA**应该卖的是“用户自己的 AI 股票研究工作台”。

因此，DSA 不需要在新闻、图表或 Level 2 行情上正面超过所有对手。只要把 **A股、港股、美股研究 + AI 分析 + 自选模型 + 自己的 API + 本地模型**做得简单好用，就有明确差异。

## 各产品优劣势

### 1. HKET

**优势：** 香港本地品牌强，新闻更新快，专栏、报刊、港股报价和提醒容易形成每日阅读习惯。

**劣势：** 用户主要是“看别人写好的内容”，不能围绕自己的自选股持续生成个性化研究。

**DSA 怎么竞争：** 不和它抢新闻编辑，而是让用户把新闻和股票数据变成自己的 AI 研究报告。

### 2. 经济一周

**优势：** 专家、访谈、直播、教学和社群有温度，用户容易建立信任。

**劣势：** 内容是一对多，同一份内容未必适合每个用户的持仓、自选股和研究问题。

**DSA 怎么竞争：** 突出“每个人都有自己的 AI 研究助手”，报告围绕用户选定的股票和问题生成。

### 3. AASTOCKS

**优势：** 香港用户熟悉，港股数据、异动监察、自选和提醒具有本地市场优势。

**劣势：** 核心偏行情和监察，不以多模型 AI 研究、用户 API 或本地模型为主要卖点。

**DSA 怎么竞争：** 重点做 A股、港股、美股统一研究，并解释“为什么出现变化”，而不只是告诉用户“发生了变化”。

### 4. TradingView

**优势：** 图表、技术指标、提醒、脚本和全球市场生态最成熟，Web、桌面和手机体验完整。

**劣势：** 高级套餐价格较高，交易所数据可能额外收费；功能很多，新用户需要时间学习。

**DSA 怎么竞争：** 不复制完整图表系统，主打“一键生成看得懂的研究”，降低普通用户使用门槛。

### 5. ET Net IQ

**优势：** 港股 Level 2 串流、十档盘口、经纪排位、成交和资金流数据专业度高。

**劣势：** HK$570/月价格高，适合专业即市用户，不适合所有普通投资者。

**DSA 怎么竞争：** 面向不需要 Level 2、但希望获得 AI 研究和多市场分析的个人用户。不能宣传 DSA 可以替代 Level 2 终端。

### 6. DSA

**优势：**

- 同时覆盖 A股、港股和美股。
- 平台模型、用户自己的 API 和用户本地模型可以自由选择。
- 从筛选、研究、报告到自选和提醒可以形成完整流程。
- PRO HK$78、MAX HK$188，价格低于大部分工具型产品。
- 本地模型有隐私和长期使用成本优势。

**劣势：**

- 品牌、用户信任和付费口碑还没有成熟竞争者强。
- 港股实时深度数据不及 ET Net IQ，图表不及 TradingView。
- 新闻编辑、专家内容和社群不及 HKET、经济一周。
- 真实支付、真实 BYOK、Windows/Mac 正式发布和数据授权仍需完成。
- PLUS 容易被理解成“交了会员费还要自己付 API 费”，页面必须讲清楚其真正价值。

| 套餐 | 判断 | 建议 |

| PLUS HK$58 | 有特色，但最难解释 | 主打自己的 API、本地模型、隐私、历史和研究工具，不要主打赠送次数 |
| PRO HK$78 | 性价比最好 | 作为首页“推荐套餐”和主要销售目标 |
| MAX HK$188 | 次数很多，价格有优势 | 面向高频 AI 研究用户，不写成专业行情终端 |

## DSA 最应该强调的三件事

1. **一个网站研究三个市场：** A股、港股、美股不用来回切换工具。
2. **模型由用户选择：** 可以用平台模型、自己的 API，或自己电脑里的模型。
3. **研究过程更简单：** 用户选股票和问题，系统帮助完成资料整理、分析、报告、自选和提醒。

建议首页用语：

> DSA 是面向香港投资者的多市场 AI 研究工作台。
> 一站研究 A股、港股和美股，自由选择平台模型、自己的 API 或本地模型。

## 最终判断

DSA 当前最直接的竞争优势不是“数据最多”或“图表最强”，而是：

> **比传统财经内容更个性化，比专业图表和 Level 2 终端更简单，也比一般 AI 股票工具更开放。**

最适合主推 **PRO HK$78/月**。这个价格只比 HKET 高 HK$18，却比经济一周、AASTOCKS 和 TradingView Essential 便宜，同时最容易让普通用户理解“我付钱后可以直接使用平台 AI 做研究”。

DSA 的最大风险也很清楚：如果数据准确性、产品易用性和品牌信任没有做好，再低的价格也不能长期留住用户。因此第一阶段应优先做好研究结果可信、首次使用简单、PRO 权益清楚，而不是急着补齐所有新闻、图表和 Level 2 功能。
