# DSA API、会员与 BYOK 对话纪要

日期：2026-07-11
用途：保存当天产品讨论和技术核对结论，供后续开发、定价和验收继续使用。
安全说明：本文不记录任何真实 API Key、密码、支付凭据或用户隐私数据。

## 1. 已确定的产品原则

1. DSA 只提供市场资讯、公开或授权数据、指标计算和信息分析。
2. DSA 不提供个性化投资建议、买卖指令、仓位建议、目标价、收益承诺或代客决策。
3. 所有 AI 报告和页面需要持续显示“仅供信息分析，不构成投资建议”等风险提醒。
4. 免费版是用户留存和付费转化的核心，不能只显示简单股价。
5. 免费版与高级版尽量保持相同的信息模块；主要区别放在数据时效、数据源、AI 模型深度、查询额度、历史保存和提醒能力。
6. 正式会员等级为五级：游客、普通客户、PLUS、PRO、MAX；其中游客和普通客户免费，PLUS、PRO、MAX 月价分别为 HK$58、HK$78、HK$188。
7. PLUS 保留与普通客户完全相同的免费赠送额度：每周 5 次 Flash + 每周 1 次 Pro；PLUS 付费本身不额外增加平台模型额度，主要解锁用户自己的官方 API Key（BYOK）、用户自有本地模型通道和会员功能。PRO 和 MAX 才提供额外付费平台模型额度。
8. PRO 与 MAX 采用“单用户月度贡献利润”口径：两档都维持接近每月 HK$50 的贡献利润，并把超出目标的预算优先转化为更多 API 次数；该数字不等于公司会计净利润。
9. MAX 的 API Token 按保守成本预算提供，不额外赚取 Token 差价；在保留约 HK$50 月度贡献利润的前提下，尽量把剩余预算转化为更多平台 API 查询次数。

## 2. 当前确认的五级会员结构

### 2.1 游客

- 可以使用无需 AI 的网络数据查询。
- 按 IP、设备标识、Cookie 和风控规则赠送 5 次普通平台 API 查询。
- 5 次用完后仍可继续使用无需 AI 的基础网络查询。
- 不开放高级模型、BYOK、长期历史和高级提醒。
- IP 和设备识别需要在隐私政策中说明用途、保存期限和删除方式。

### 2.2 普通客户

- 可以继续使用网络数据查询。
- 赠送一定数量的普通平台 API 查询和少量高级模型体验。
- 可以保存有限历史、自选股和条件提醒，以形成持续回访。
- 当前确认基准：每周 5 次普通模型查询，每周 1 次高级模型体验；注册首月额外赠送 1 次高级体验。

### 2.3 PLUS

- 当前价格：HK$58/月、HK$158/季、HK$568/年。
- 保留普通客户的免费赠送额度：每周 5 次 Flash + 每周 1 次 Pro；PLUS 不因付费额外增加平台模型额度。
- 如果账号仍处于注册首月，继续享有普通客户的首月额外 1 次 Pro；升级 PLUS 不会重新触发或重复发放首月奖励。
- 免费赠送额度之外的 AI 分析使用用户自己的官方 API Key，或在技术通道完成后使用用户自有本地模型。
- 用户可以从自己 API Key 或自有本地模型实际支持的模型目录中选择模型。
- PLUS 仍受 DSA 服务器、数据源、并发和防滥用公平使用上限约束；“自有 API”不等于无限占用 DSA 计算和数据服务。
- “用户自有本地模型”不等于把 DSA 服务器上的 Ollama 作为公网会员主模型。当前纯 Web 产品尚需单独完成安全连接方案，未完成前 PLUS 先提供 BYOK。
- 获得付费会员对应的历史、自选、提醒、筛选、比较和报告保存能力；具体数量由功能策略表单独定义。

### 2.4 PRO

- 当前价格：HK$78/月、HK$218/季、HK$888/年。
- 每个会员月赠送 268 次 Flash + 28 次 Pro 平台模型额度。
- 同时保留 BYOK 和用户自有本地模型能力。
- 可以从 PRO 获准模型目录中自主选择模型；不同成本模型可以消耗不同数量的高级额度。
- 获得比 PLUS 更多的历史、自选、提醒、筛选、比较和报告保存能力。

### 2.5 MAX

- 当前价格：HK$188/月、HK$558/季、HK$2,188/年。
- 每个会员月赠送 1,688 次 Flash + 168 次 Pro 平台模型额度。
- 同时保留 BYOK 和用户自有本地模型能力。
- 可以从完整获准模型目录中自主选择模型，包括官方直连和管理员批准的中转线路；页面必须显示真实供应商、模型和线路。
- 高成本旗舰模型按实际成本和三倍安全预算消耗多个高级额度，不能把所有模型都按一次查询扣减。
- 获得最高的历史、自选、提醒、筛选、批量比较、报告保存和并发优先级。
- MAX 不以 Token 差价盈利；真实 Token 成本下降后，在维持约 HK$50 月均贡献利润的前提下优先增加或校准 API 查询次数。

### 2.6 API 加油包（初版建议，待最终确认）

- 为 API 次数用完的有效 PRO/MAX 用户提供一个混合加油包；PLUS 仍以 BYOK 和用户自有本地模型为主，不通过加油包改变其产品定位。
- 初版建议价格保持 HK$28/包，每包增加 168 次 Flash + 28 次 Pro；价格和两类次数都以“8”结尾，按当前保守成本测算，单包贡献利润率约 29.7%。
- 加油包只增加当前会员等级可用的 API 次数，不升级会员等级、模型目录、并发优先级、历史、自选、提醒或其他会员权益。
- 购买成功后立即入账并单独记入额度流水；会员基础额度优先扣减，加油包额度随后扣减。
- 加油包额度最迟在当前会员月结束或会员 `expires_at` 到达时失效，以较早者为准；未用额度不退款、不折现、不转让、不结转。
- 结算前必须显示准确失效时间和剩余可用时长；购买次数受后台可配置的单用户和全站预算风控限制。

### 2.7 会员期限与 API 额度失效规则

- 月包有效 1 个会员月，季包有效 3 个会员月，年包有效 12 个会员月。
- 季包和年包仍按会员月逐月发放 API 额度，不在付款当天一次性发完全部季度或年度额度。
- 每个会员月未使用的 Flash、Pro 或其他会员 API 额度在该会员月结束时自动失效，不结转到下一个会员月。
- 会员到期时间以服务端 `expires_at` 为准；到期后立即降回非会员权限，任何剩余会员 API 额度同时失效，不能继续使用。
- 未使用额度不退款、不折现、不转让、不兑换现金，也不因续费而结转；法定退款、平台重大故障补偿或运营人工补偿另按单独政策处理。
- 提前续费只延长新的会员期限并按新周期发放额度，不恢复已经失效的旧额度。
- BYOK 和用户自有本地模型是 PLUS、PRO、MAX 的付费会员能力。会员到期后不能再通过 DSA 发起对应分析，但仍可进入账号页禁用、更新或删除自己已保存的密钥。
- 请求提交和实际调用模型前都要检查会员有效期；到期前已提交但尚未调用模型的排队任务，在到期后不得继续消耗会员 API。

## 3. DeepSeek 成本与定价讨论

详细成本公式和香港同类会员市场调研保存在：

- `docs/superpowers/plans/2026-07-11-dsa-membership-api-pricing-market-research.md`

当天讨论采用的保守原则：

- 不只按理论 Token 费用计算运营成本。
- 预算中为长输出、重试、超时、缓存未命中、汇率和价格变化预留约 3 倍缓冲。
- PLUS 当前 HK$58 月付，保留普通客户每周 5 次 Flash + 每周 1 次 Pro 的免费成本基线；月费不购买额外平台额度，主要覆盖 BYOK/用户自有本地模型接入、DSA 数据和会员功能服务。
- PRO 当前 HK$78 月付，平台额度由原每月 98 次 Flash + 8 次 Pro 提高至 268 次 Flash + 28 次 Pro，测算月度贡献利润约 HK$49.67；本次价格上调产生的空间优先转换成更多平台 API 查询次数。
- MAX 的 Token 预算按成本转交给用户，不设置额外 Token 利润；月付 HK$188 下提供 1,688 次 Flash + 168 次 Pro，测算月度贡献利润约 HK$52.70。
- 包季和包年只提供轻微价格优惠，API 额度仍按会员月发放和清零；到期后剩余额度失效，不退款、不结转。
- 免费用户额度必须配合账号、IP、设备、并发和自动化行为风控。
- DeepSeek 企业客户暂未发现公开统一的专属低价表，企业折扣需要单独商务询价，不能提前计入商业模型。
- 第三方 Token 中转站即使报价低，也可能存在密钥、日志、模型冒充、停服、账单和合规风险；平台默认应优先使用官方 API 或可审计的正式云渠道。
- ChatGPT 会员和 Claude.ai 会员不等于 API 套餐；用户必须提供开发者平台签发并单独计费的 API Key。

## 4. Ollama 的定位决定

1. Ollama 只作为本地开发、自动测试、内部评估和必要时的内部降级通道。
2. DSA 服务器上的 Ollama 不作为公网普通客户或付费会员的主要 AI 服务；PLUS、PRO、MAX 所称“本地模型”专指用户自己的本地模型。
3. 原因包括单机并发、显存容量、排队延迟、模型维护、可用性和服务隔离不适合直接承担大规模会员请求。
4. 本地模型结果只能作为信息分析，不得包装成确定性预测或交易建议。

## 5. 模型能力差异结论

模型能力越高，报告通常会在以下方面出现差异：

- 多来源信息整合和矛盾识别；
- 长财报、公告和多篇资讯的上下文理解；
- 技术指标、估值、基本面和风险因素之间的关联解释；
- 数据缺失、不确定性和限制条件的说明；
- 报告结构、语言质量和可读性。

但是，模型更强不代表行情事实自动更准确。数据来源、更新时间、复权方式和字段完整度决定事实基础；模型只负责在这些数据之上进行信息整理和解释。过期或错误数据交给更强模型，仍然可能生成流畅但不可靠的报告。

DSA 应统一不同模型的输出：

1. 使用同一份带时间戳的数据快照。
2. 使用统一的信息分析提示词和禁止投资建议规则。
3. 使用统一结构化输出字段。
4. 展示数据来源、更新时间、数据完整度、模型供应商和模型名称。
5. 对输出进行合规后处理，拦截买卖指令、仓位建议、目标价和收益承诺。
6. 保存请求成本、耗时、失败类型和模型版本，便于质量与成本比较。

## 6. GPT、Claude 与客户 BYOK

产品方向：PLUS、PRO、MAX 可以在 DSA 中保存自己的 OpenAI、Anthropic Claude、DeepSeek 或其他获准供应商 API Key，然后选择模型生成报告；PLUS 只保留普通客户的免费赠送额度，不获得额外付费平台额度。

安全要求：

- API Key 只在服务端加密保存。
- 页面只显示掩码，不返回明文。
- 日志、审计 metadata、错误信息和前端状态不得包含完整密钥。
- 每次请求必须明确绑定用户、供应商、模型和密钥记录。
- 用户可以禁用、更新和删除自己的密钥。
- 不允许普通用户自定义任意 Base URL，避免 SSRF 和恶意中转风险；只允许管理员审核过的供应商或域名。
- 页面需要说明数据会发送到用户选择的外部模型供应商，并链接相应隐私和数据保留政策。

## 7. 当前 DSA 的真实支持状态

当前代码不是完全不支持 GPT 或 Claude，而是“底层能力和界面已经存在，会员 BYOK 路由尚未完整闭环”。

已经具备：

- 前端供应商选项包含 DeepSeek、OpenAI、Anthropic 和 Gemini。
- 后端允许保存上述供应商的用户 API Key，并进行加密和掩码处理。
- LiteLLM 配置层具备 OpenAI 与 Anthropic 模型通道。
- 分析服务已有 `platform`、`user` 和 `local` 三种 API Key 模式。

尚未闭环：

- 用户保存的模型名称尚未可靠绑定到每次分析请求的实际 `litellm_model`。
- 用户模式目前按固定顺序寻找已保存密钥，而不是严格使用用户本次选择的供应商和密钥记录。
- 如果用户同时保存多家密钥，存在调用供应商与界面选择不一致的风险。
- 当前 BYOK 自动测试重点覆盖 DeepSeek，尚缺 OpenAI 和 Anthropic 的完整路由、错误、配额和隔离测试。
- `anthropics/financial-services` 是研究工作流和方法参考，不等于已经配置 Claude API。

因此，现阶段不能对外宣传“GPT/Claude BYOK 已完全可用”。

## 8. 后续开发优先级

1. 为分析请求增加明确的 `provider`、`model` 和 `api_key_id`，不再依赖固定顺序猜测供应商。
2. 用户选择 OpenAI 时只能使用该用户的 OpenAI Key；选择 Anthropic 时只能使用该用户的 Anthropic Key。
3. 将数据库中保存的模型名称安全地应用到请求级配置，并设置供应商模型白名单。
4. 分别补齐 DeepSeek、OpenAI、Anthropic 的模拟调用、超时、余额不足、无权限、模型不存在和限流测试。
5. 用受控测试账号完成一次真实 OpenAI 和 Claude API 验收；真实密钥不得进入代码、文档、日志或 Git。
6. 统一各供应商输出结构、合规拦截、语言切换和成本记录。
7. 根据真实查询 Token 分布重新计算会员额度：PRO 和 MAX 都维持接近月均 HK$50 的贡献利润且不赚 Token 差价，成本下降时优先增加查询次数。
8. 五级会员和当前价格已确认：游客免费、普通客户免费、PLUS 为 HK$58/月、HK$158/季、HK$568/年，PRO 为 HK$78/月、HK$218/季、HK$888/年，MAX 为 HK$188/月、HK$558/季、HK$2,188/年。
9. 会员 API 按会员月发放并在会员月末清零；会员到期后剩余额度立即失效，不退款、不折现、不转让、不顺延。

## 9. 明天继续时的简短入口

继续任务时先读取本纪要和会员成本调研文档，然后核对主线程 V107 当前代码与 Git 状态。优先完成多供应商 BYOK 的请求级路由闭环；不要把 Ollama 作为公网会员主要模型，也不要把金融信息分析表述成投资建议。
