# DSA V99 自选股事件雷达与每日复盘实施计划

## 目标

在不接入真实支付、生产密钥或公共搜索的前提下，把现有“自选股价格刷新”升级为可每日重复使用的事件雷达。免费版与高级版使用相同的信息结构；差异仅体现在处理数量、来源深度、刷新能力和自动化边界，不隐藏基础行情与风险提示。

## 产品契约

1. 雷达仅对当前登录平台用户的自选股工作，不读取或展示其他用户数据。
2. 默认不调用 AI，不消耗平台 AI、BYOK 或本地模型额度。
3. 行情变化、均线位置、量价状态和数据质量由当前快照确定性生成。
4. 只有具备标题、来源、时间和可追溯 URL 的已入库资讯才标记为真实来源事件；占位文案不得伪装成新闻、公告或研报。
5. 免费版和高级版使用同一雷达布局。免费版每次处理前 10 个自选标的，高级版最多 50 个；未处理标的继续保留在用户自选列表中。
6. 事件按严重性、变化幅度和标的代码稳定排序，输出最强、最弱、风险标记数、真实来源事件数和建议提醒条件。
7. 建议提醒只作为用户可见的观察条件，不写入现有全局提醒表，避免突破用户归属边界。
8. 所有股票分析仅供信息分析，不构成投资建议。

## 实施步骤

### 1. 后端事件雷达

- 扩充自选刷新数据：MA5、MA20、5/20 日涨跌、量能相对 MA5、量价信号、更新时间。
- 新增用户自选雷达服务，聚合行情变化、趋势、量价、数据质量与可追溯资讯。
- 新增只读平台接口 `/api/v1/platform/watchlist/radar`。
- 输出套餐处理上限和未处理数量，但不改动自选表。

### 2. 前端今日变化看板

- 新建独立雷达组件和展示模型，避免继续扩大 `HomePage.tsx` 的内联复杂度。
- 显示今日摘要、优先级事件、原因、数据状态、来源链接、下一步观察和提醒建议。
- 中文模式完整中文，英文模式完整英文；代码、公司名和官方来源名可保留原文。
- 空态、降级态和来源不足均明确说明，不制造“已获取实时新闻”的错觉。

### 3. 留存与套餐边界

- 免费版保留完整结构与核心判断，最多处理 10 个自选标的。
- 高级版最多处理 50 个标的，并预留更多来源、历史回看和自动提醒能力文案。
- 本阶段不接真实支付，不改变现有 AI 配额规则。

### 4. 验收

- 后端单元测试：用户隔离、套餐上限、无 AI、事件排序、真实来源过滤、降级数据。
- 前端测试：中英文、空态、免费/高级边界、来源链接与提醒建议。
- 前端 lint/build、后端相关回归、V99 verifier。
- 浏览器实际登录并验证 A 股、美股、港股、加密货币自选雷达；确认无空白页、无横向溢出、无密钥泄漏。
- 更新 `docs/CHANGELOG.md` 和本地验收文档；最终保持工作树可审查，不提交或推送，除非潘总另行确认。

## 回滚

删除 V99 雷达路由、服务、组件和对应测试，并恢复自选刷新新增字段即可。自选表、用户表、历史报告和 API Key 数据均不迁移、不删除。
