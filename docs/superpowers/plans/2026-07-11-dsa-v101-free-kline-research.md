# DSA V101 免费历史走势研究台

## 目标

把免费快速分析中的文字 K 线情景补成可核验的真实历史走势证据：游客可切换区间，查看收盘价、MA5/MA20、成交量、区间表现、最大回撤和关键位置，不调用 AI，不启用公共搜索。

## 契约

1. 复用公开 `GET /api/v1/stocks/{symbol}/history`，不要求登录。
2. 支持 30、90、180、365 日，默认 90 日；切换区间只重新读取历史行情。
3. 展示真实收盘价、MA5、MA20、成交量和来源，不把规则计算称为模型预测。
4. 展示区间涨跌、高低点、最大回撤、量能相对 5 日均量和明日观察条件。
5. 数据不足、空数据或网络失败必须明确降级，不展示原始 provider 异常。
6. 快速快照已有收盘线时必须先即时展示，再在后台补齐完整区间；外部历史源失败不得让已有证据消失。
7. 中文模式全部中文，英文模式全部英文；移动端不得横向溢出。
8. 全流程 `ai_used=false`，不消耗平台、BYOK 或本地模型额度，仅供信息分析，不构成投资建议。

## 验收

- API 客户端验证 snake_case 到 camelCase 转换及区间参数。
- 组件验证中文、英文、区间切换、指标、空态和失败降级。
- HomePage 快速分析集成验证游客可见、查询简版不自动加载、AI 接口未被调用。
- 运行前端全量、lint、build、V101 verifier、release package、V1 operability 和浏览器桌面/移动验收。
