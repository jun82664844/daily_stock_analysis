# DSA V100 自选事件、私有提醒与每日复盘闭环

## 目标

把 V99 的即时事件雷达升级为可重复回访的用户闭环：用户可以保存提醒条件、每天运行雷达、查看最近复盘记录，并看到本次真正触发的提醒。全流程默认不调用 AI，不接真实支付、生产密钥或公共搜索。

## 核心契约

1. 雷达运行、提醒规则和触发记录全部按 `platform_user_id` 隔离。
2. 免费版和高级版保留相同页面结构；免费版最多 3 条启用提醒并处理 10 只自选，高级版最多 50 条提醒并处理 50 只自选。
3. 支持价格涨跌、MA20 穿越、量能变化、来源更新和数据质量提醒。
4. MA20 穿越必须对比上一次已保存雷达，不得把首次观察伪装成穿越。
5. 只有具备 HTTP(S) 原始链接、来源和时间的已入库资讯可以触发来源更新提醒。
6. 雷达历史保存经过裁剪的无密钥 JSON；不得保存 API Key、Token、密码、原始 provider 异常或完整 AI 报告。
7. 删除规则统一内部停用并从列表隐藏，保留历史事件到规则的可追溯关联，并规避运行/删除并发产生悬空引用。
8. 当前套餐在每次列表和执行时重新限制规则数量；付费降级为免费后最多展示和执行 3 条。
9. 前端所有私有响应必须同时匹配会话代次与 `userId`，旧请求或跨用户响应不得回填。
10. 非有限数值、重复来源 URL、缺失 CSRF 和超限删除请求必须被拒绝或去重。
11. 同一用户的雷达运行、规则保存和规则停用在本地单进程内串行化；已入库资讯匹配兼容 A 股和港股常见代码变体。
12. 所有输出仅供信息分析，不构成投资建议。

## 后端

- 新增用户雷达运行、提醒规则和提醒触发记录表。
- 新增 V100 自动化服务：运行雷达、读取上一轮、判断提醒、保存裁剪快照和触发记录。
- 新增运行、历史、提醒列表、提醒保存和提醒删除 API。
- 扩展资讯匹配：优先读取个股作用域，再以股票代码/名称在同市场已入库资讯中匹配；不主动抓取外网。

## 前端

- “生成今日复盘”改为保存一次用户雷达运行。
- 雷达区展示最近复盘时间线、本次触发提醒和已保存规则。
- 建议提醒可直接保存；已保存规则可以删除。
- 中文与英文完整对应，移动端无横向溢出。

## 验收

- 测试用户隔离、3/50 条规则上限、首次运行不误报 MA20、第二次真实穿越触发、来源 URL 过滤和删除权限。
- 前端覆盖保存提醒、删除提醒、时间线、本次触发、中英文与空态。
- 运行后端相关回归、前端全量测试、lint、build、V100 verifier、release package、V1 operability。
- 重启 8018 后实际完成多市场自选、两次雷达运行、提醒保存和历史回看。

## 回滚

移除 V100 路由、服务、组件联动和三张新增表模型即可。V99 即时雷达、既有自选、历史报告、用户、数据库和 API Key 数据不删除。
