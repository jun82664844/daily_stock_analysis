# DSA 与香港财经资讯/投资工具市场竞争调查报告

- 日期：2026-07-12
- 范围：HKET、经济一周、AASTOCKS Intelligent Stock Monitor、TradingView Essential/Plus/Premium、ET Net IQ 与 DSA 现有网站及会员规划
- 口径：官网公开价格、官网功能说明、DSA 当前本地验收状态与已确认会员方案

## 一、结论摘要

DSA 最适合的定位不是“财经媒体”、不是“Level 2 实时报价终端”，也不应直接挑战 TradingView 的专业图表能力。最有机会占领的市场空位是：

> **面向香港个人投资者的 A股、港股、美股 AI 研究工作台。**
> 用户可以使用平台模型、自己的 API 或自己的本地模型，完成市场浏览、筛选、研究、报告、自选和提醒。

主要结论：

1. **DSA 的价格具有竞争力。** PLUS HK$58 与 HKET HK$60 接近；PRO HK$78 比经济一周 HK$98、AASTOCKS HK$101 和 TradingView Essential 约 HK$101 都低；MAX HK$188 比 TradingView Plus 约 HK$234 低约 19.5%，比 ET Net IQ HK$570 低约 67%。
2. **PRO 是最适合主推的套餐。** HK$78 落在香港用户熟悉的内容订阅价格区间内，同时包含 268 次快速分析、28 次深度分析、模型选择、BYOK 和本地模型能力，差异最清晰。
3. **PLUS 的价值表达存在风险。** HK$58 已接近 HKET HK$60，但 PLUS 不额外提供平台模型次数。如果页面只写“可以使用自己的 API”，普通用户可能认为自己既付会员费又付模型费，不如购买 HKET 内容订阅。PLUS 必须突出历史、报告、自选、提醒、筛选、隐私和本地模型便利。
4. **MAX 的价格很有吸引力，但不能宣传成专业行情终端替代品。** DSA 尚未取得港股实时/Level 2 数据授权，也没有 TradingView/ET Net 的图表和串流深度。MAX 应定位为“高频 AI 研究用户”，不是“专业交易员终端”。
5. **DSA 的核心差异化非常明确。** 本次调查的传统产品都没有把“平台模型 + 用户 API + 用户本地模型”作为普通会员可自由选择的核心权益。这个差异比单纯增加图表、新闻或技术指标更有价值。
6. **当前还不能直接公网商业上线。** DSA 本地 V112 验收已通过 49 项测试，Windows Ollama 本地开发链已验证；但真实支付、真实 OpenAI/Claude BYOK、Windows 正式签名、Mac 签名/notarization 与真机、生产市场数据授权仍未关闭。

## 二、调查口径与价格修正

### 2.1 汇率

TradingView 以美元计价。本报告使用 `US$1 ≈ HK$7.80` 作展示换算。香港联系汇率制度的官方兑换区间是 7.75–7.85，因此实际信用卡入账、税费和汇率会略有变化。来源：[香港金融管理局联系汇率制度](https://www.hkma.gov.hk/eng/key-functions/money/linked-exchange-rate-system/)。

### 2.2 需要修正的价格理解

- TradingView 官网当前显示的 US$12.95、US$29.95、US$59.95 是**按年付款时折算的月价**，不是单独月付价格。
- TradingView 的交易所专业数据、税费可能另外收取，因此不能把约 HK$101/234/468 理解为包含所有实时市场数据的最终总价。
- ET Net IQ 的价格包含港股 Level 2 等专业串流数据，和 DSA 当前公开数据/研究工具不是同一成本结构。
- AASTOCKS HK$101 对应 Intelligent Stock Monitor/港股综览数据分析产品，不等于其更高价的实时报价终端产品。

## 四、竞争产品逐项分析

### 4.1 HKET hket PRO

主要能力：

- 香港财经新闻、投资/趋势/知识频道和名家专栏。
- 香港经济日报、iMoney 等刊物内容与历史新闻搜索。
- 港股即时/延时报价、投资组合、到价提示、股票和板块追踪。
- Web、手机和平板使用。

优势：

- 香港本地品牌、内容编辑和专家资源强。
- HK$60 的价格容易理解，年度折扣明显。
- 内容、即时资讯、组合和提醒形成日常使用习惯。

弱点与 DSA 机会：

- 核心仍是内容订阅和行情阅读，不是用户驱动的 AI 研究工作流。
- 没有把 BYOK、本地模型和多模型选择作为核心会员能力。
- DSA 可以提供跨 A/H/美股、按用户问题生成的结构化研究，但无法替代 HKET 的新闻团队和独家内容。

来源：[HKET 订阅福利与价格](https://plus.hket.com/account/subscribe/register)。

### 4.2 经济一周

主要能力：

- 每日投资和经济内容、深度专题、嘉宾专访。
- 选股内容、即市 Podcast、会员 Live Chat。
- 程序交易教学、电子书、电子周刊和活动。
- 浏览器、iOS、Android 跨设备阅读。

优势：

- 内容人格化、社群化，容易形成信任和付费习惯。
- 年付折扣大，HK$788/年约 HK$65.67/月。
- 教学、直播、访谈和活动不是纯工具容易复制的。

弱点与 DSA 机会：

- 内容通常是一对多，不能针对用户的自选股持续生成个性化研究。
- 缺乏统一的市场筛选、数据链路、模型选择和本地隐私计算。
- DSA 不应模仿“猛人选股”，应强调可追溯数据、研究过程和信息用途，减少投资建议风险。

来源：[经济一周订阅计划](https://www.edigest.hk/subscription-plan/)。

### 4.3 AASTOCKS Intelligent Stock Monitor

主要能力：

- 港股基本面和技术面数据库。
- 覆盖大量行业分类和预设筛选类别。
- 智慧选股、股票筛选、公司数据库、市场纵览和技术分析。
- 可生成自定义分析报告并导出 Excel。

优势：

- 香港股票资料深度、品牌认知和本地用户基础强。
- 与 DSA 的市场筛选、公司研究和报告功能重叠最多，是较直接的工具型竞争者。
- HK$101 是香港用户已经接受的股票数据库/监察工具价格锚点。

弱点与 DSA 机会：

- 产品重点是数据库、筛选和固定报告，不是自然语言、多模型、BYOK 和本地模型工作流。
- DSA 可以把筛选原因、事件、研究报告、自选和提醒串成一个闭环。
- DSA 当前港股数据深度、授权和品牌仍弱于 AASTOCKS，不能只靠 AI 文案弥补。

来源：[AASTOCKS 产品功能](https://www.aastocks.com/en/Product/ProductDetail.aspx?product=7)、[官方订阅表](https://accounts.aastocks.com/Resources/forms/SHK_Subscription_Form_EN.pdf)。

### 4.4 TradingView

主要能力：

- 全球市场、大量品种和成熟图表。
- Essential/Plus/Premium 分别增加图表数量、指标、历史 bars、并行连接和提醒数量。
- Web、桌面、移动端，多设备同步。
- 技术指标、回放、数据导出、自定义公式、社区脚本和经纪商交易。

优势：

- 图表、指标、提醒、全球市场和社区生态是调查产品中最强的。
- 品牌全球化，产品成熟，跨设备体验完整。
- 免费版已经能满足大量基础需求。

弱点与 DSA 机会：

- 高级套餐和额外实时市场数据成本较高。
- 核心仍是图表、数据和交易工作台；针对香港用户的中文 AI 研究、BYOK、本地模型不是核心卖点。
- DSA 不应复制其图表系统，而应让研究结果更容易解释“为什么值得继续观察、哪些条件发生变化、下一步看什么数据”。

来源：[TradingView 官方定价和功能比较](https://www.tradingview.com/pricing/)。

### 4.5 ET Net IQ

主要能力：

- 港股 Level 2 自动串流报价、十档买卖盘、经纪排位和完整成交纪录。
- 即时图表、挂盘、成交、资金流向、大户追踪。
- 沪深港通资金、盈利预测、公司日历、期货和期权信息。
- Web、桌面、平板和手机跨设备。

优势：

- 专业实时行情、市场深度和香港本地数据能力最强。
- 月费 HK$570 的高价格有明确的数据授权和专业终端支撑。
- 适合日内交易、盘口和资金流向用户。

弱点与 DSA 机会：

- 价格远高于大众内容订阅和 DSA。
- 对中低频个人投资者可能信息过载。
- DSA 可以服务“不需要 Level 2，但需要跨市场筛选、解释和研究报告”的用户。
- 在未取得相同数据授权前，DSA 不能宣传自己是 ET Net IQ 的低价替代品。

来源：[ET Net IQ 产品和收费](https://www.etnet.com.hk/www/tc/product/iq/index.php)。

## 五、DSA 当前产品状态

### 5.1 已存在并有本地证据的能力

- `/market` 支持游客查看 A股、港股、美股总览、搜索、涨跌图和来源状态。
- 登录用户可以保存自选、价格条件提醒、研究历史和每日研究摘要。
- 已有市场筛选、解释性结果、结果比较和条件提醒。
- 已有研究工作流、组合、决策信号、回测、提醒、聊天、用量和账号页面。
- V112 已有加油包沙箱、统一模型目录、三步 BYOK 页面和用户 Ollama 连接器代码。
- HK$28 API 加油包在本地沙箱中按每包 168 Flash + 28 Pro 实现，真实支付尚未上线。
- Windows Ollama 本地开发链已有真实本地证明；V112 确定性验收在项目虚拟环境中运行 49 项测试并通过，输出：

```text
DSA_PLATFORM_SIMPLE_MODEL_ACCESS_V112_OK boost=168+28 price_hkd=28 sources=platform,byok,user_local platforms=windows,macos secrets_exposed=false
```

### 5.2 尚未完成、不能对外宣传的能力

- 没有真实支付上线；当前为 sandbox/本地生命周期。
- 真实 OpenAI/Claude BYOK 尚未完成受控验收。
- macOS Intel/Apple Silicon 连接器真机、Developer ID 签名和 notarization 尚未完成。
- Windows 正式包签名尚未完成。
- 公网生产部署、生产密钥、WAF/CDN、正式法律条款和隐私政策尚未关闭。
- 港股实时行情和 Level 2 市场数据授权尚未完成。

因此，报告中的 DSA 价格和会员权益是**已确认商业方案和本地实现基线**，不是已经可以公开收费的线上服务。

## 七、价格竞争力分析

### 7.1 PLUS HK$58

- 比 HKET 月付 HK$60 低约 3.3%。
- 年付月均 HK$47.33，比 HKET 年付月均 HK$49.83 低约 5%。
- 价格本身合理，但两者价值不同：HKET 提供大量内容和即时资讯；DSA PLUS 主要提供 BYOK/本地模型和研究工具。
- 如果 PLUS 页面没有清楚列出历史、自选、提醒、筛选、报告保存和本地隐私价值，用户会认为 HKET 更“有东西看”。

结论：**价格可以保留，但必须重新包装价值，不适合作为主推套餐。**

### 7.2 PRO HK$78

- 比经济一周 HK$98 低约 20.4%。
- 比 AASTOCKS HK$101 低约 22.8%。
- 比 TradingView Essential 折算约 HK$101 低约 22.8%。
- 价格仍处于香港用户熟悉的普通订阅区间，同时包含平台 AI 次数。

结论：**PRO 应成为“最受欢迎/推荐”套餐，是 DSA 最强的商业切入点。**

### 7.3 MAX HK$188

- 比 TradingView Plus 折算约 HK$234 低约 19.5%。
- 年付月均 HK$182.33，比 TradingView Plus 约 HK$234 低约 21.9%。
- 比 ET Net IQ 月付 HK$570 低约 67%。

结论：**价格吸引力强，适合高频 AI 研究用户；不能用价格差暗示拥有同等级实时行情或专业图表。**

### 7.4 PRO 长期价格存在一个小问题

| 期限 | 总价 | 月均 |
| --- | ---: | ---: |
| 月付 | HK$78 | HK$78.00 |
| 季付 | HK$218 | HK$72.67 |
| 年付 | HK$888 | HK$74.00 |

年付月均 HK$74 反而高于季付月均 HK$72.67。用户可能会问“为什么承诺一年，反而没有季付便宜”。

可选处理：

1. 把 PRO 年价调整为 HK$868，仍保留香港用户喜欢的“8”；或
2. 保留 HK$888，但增加明确的年度专属权益，使年付总价值高于连续季付。

本报告只提出问题，不修改已确认价格。

## 八、DSA 的最佳市场定位

### 8.1 推荐定位

> **香港投资者的 AI 研究工作台**
> 一个账户研究 A股、港股和美股；平台模型、自己的 API、本地模型自由选择。

### 8.2 不建议使用的定位

- “香港最专业实时行情终端”——目前没有 Level 2 和相应授权。
- “TradingView 替代品”——图表、社区、脚本和移动端成熟度有明显差距。
- “AI 选股必赚工具”——有合规、信任和误导风险。
- “无限 AI”——模型成本和公平使用不支持。

### 8.3 最适合的目标用户

1. 同时关注 A股、港股和美股的香港个人投资者。
2. 不需要 Level 2 盘口，但希望快速理解股票、筛选原因和事件变化的用户。
3. 已有 OpenAI/Claude/DeepSeek API，希望把 Key 用在财经研究工作流中的用户。
4. 重视隐私、已有高性能 Windows/Mac，希望运行本地模型的用户。
5. 希望保存研究历史、自选和提醒，而不是每天只看一篇专家文章的用户。

不应优先争夺：依赖十档盘口、经纪席位、毫秒级串流和专业多屏图表的日内交易用户。

## 九、网站呈现建议

### 9.1 首页第一屏

建议文案：

```text
一个工作台，研究 A股、港股和美股

平台 AI、自己的 API、本地模型自由选择
从市场浏览、股票筛选到研究报告和提醒，一次完成

[免费开始] [查看会员]
```

第一屏不要出现 API Base URL、Token、Ollama 端口、模型内部名称和复杂额度规则。

### 9.2 只展示四个用户可理解的套餐

定价页对外展示：

- 免费版
- PLUS
- PRO（推荐）
- MAX

“游客”和“普通客户”是系统身份，不必作为两个并列价格卡片，否则用户会认为有五种套餐，增加理解成本。

### 9.3 把技术名词换成用户语言

- `Flash` → “快速分析”
- `Pro` → “深度分析”
- `BYOK` → “使用我的 API”
- `Local model` → “使用我的电脑模型”
- `API 加油包` 可以保留，香港用户容易理解。

示例：

```text
PRO  HK$78/月
每月 268 次快速分析 + 28 次深度分析

```

### 9.4 比较页不要只比功能数量

建议使用三类产品定位图：

| 用户真正需要什么 | 更适合的产品 |

## 十、上线前差距优先级

### P0：收费前必须关闭

1. 真实支付、签名 webhook、退款/取消/对账和香港用户可接受的支付方式。
2. OpenAI、Claude、DeepSeek 真实受控 BYOK 验收。
3. Windows 正式签名；macOS Apple Silicon/Intel 真机、Developer ID、notarization 和下载验证。
4. 港股实时数据、新闻和公司资料的授权边界；未经授权不写“实时”或“Level 2”。
5. 隐私政策、用户条款、API Key 数据处理说明和账号删除/导出流程。
6. 公网生产安全、监控、备份恢复、故障降级和成本熔断。
7. 定价页准确展示按会员月清零、到期失效、不结转以及加油包规则。

### P1：影响转化和留存

1. 移动浏览器/PWA 体验；竞争者基本都有成熟手机入口。
2. 自选和提醒的推送可靠性、邮件/浏览器通知。
3. 更成熟的图表、研究导出和分享，但不复制 TradingView 全部能力。
4. 新用户三步引导：选市场 → 查股票 → 完成第一次免费分析。
5. PLUS 权益说明和 PRO 推荐逻辑。
6. 数据来源、新鲜度、缺失和降级状态透明展示。

### P2：确认商业需求后再做

1. 港股 Level 2 数据合作。
2. 券商连接和交易入口。
3. 专业脚本社区或指标市场。
4. 自建财经内容团队。

这些项目成本高，容易让 DSA 偏离 AI 研究工作台定位。

## 十一、SWOT

### 优势

- 平台模型、BYOK、本地模型三种方式统一选择。
- A股、港股、美股研究工作流统一。
- 定价低于主要工具型竞争者。
- 筛选、研究、自选、历史、提醒和报告可以形成闭环。
- 本地模型带来隐私和长期成本优势。

### 弱点

- 品牌、内容、市场数据深度和用户信任仍处早期。
- 真实支付和生产部署未完成。
- 图表、移动端和专业实时行情不及成熟竞争者。
- PLUS 对普通用户的价值可能不够直观。

### 机会

- 香港市场在“内容订阅”和“昂贵专业终端”之间存在价格和功能空档。
- 用户对 AI 研究、自己的 API 和本地隐私计算的接受度提升。
- 多市场投资者需要统一工作台，而本地产品多聚焦港股。

### 威胁

- TradingView、AASTOCKS、HKET 和 ET Net 都可以增加 AI 功能。
- 港股实时数据授权可能显著提高成本。
- 模型价格、输出长度和重试可能令 API 次数预算失真。
- 若 AI 结果出现事实错误或被理解为投资建议，会直接损害信任并产生合规风险。

## 十二、建议决策

### 建议立即确定

1. 将 DSA 定位锁定为“香港投资者的多市场 AI 研究工作台”。
2. 以 PRO HK$78 作为推荐套餐和主要转化目标。
3. 保留 PLUS HK$58，但强化工作流、隐私、本地模型和历史权益表达。
4. MAX 面向高频研究用户，不宣传成 Level 2 或专业交易终端。
5. 定价页使用“快速分析/深度分析”，不直接向普通用户展示 Flash/Pro 技术名。
6. 首版坚持 Windows + macOS 本地连接器，但在签名和真机完成前不公开宣传可用。

### 建议验证后决定

1. PRO 年价采用 HK$868，或保留 HK$888 并增加年度专属价值。
2. 香港实时数据是否采购，先以目标用户对 Level 2 的真实需求决定。
3. 是否增加移动 App，先验证 PWA 和移动 Web 的使用率。
4. 是否支持中转站模型，先完成供应商合规、稳定性、模型真实性和隐私评估。

## 十三、最终判断

从香港公开市场看，DSA 的价格不是主要问题，甚至明显有优势。真正决定能否成功的是：

1. 用户能否在一分钟内理解 DSA 与新闻网站、图表工具、Level 2 终端的区别。
2. 用户能否不用理解 API、端口和模型名，就完成第一次有价值的研究。
3. 数据是否准确、来源是否透明、错误是否诚实降级。
4. 真实支付、真实 BYOK、Windows/Mac 签名和市场数据授权能否在收费前关闭。

如果这些条件完成，DSA 在 HK$78 的 PRO 档具有最强的市场切入机会；如果没有完成，即使价格更低，也难以替代成熟品牌带来的信任、数据和使用习惯。
